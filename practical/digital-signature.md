Digital Signature Practical
1. Objective
Demonstrate signing and verification of a test email.
2. Test Procedure
1. Create a test signing identity.
2. Configure the email client.
3. Sign a test message.
4. Send the message to another test account.
5. Verify the digital signature.
6. Record the result.
3. Integrity Test
A copy of the signed message can be modified in a controlled test to demonstrate that verification detects the change.
Do not modify or interfere with real users' messages.
4. Expected Result
A valid signed message should pass signature verification.
A modified message should cause verification to report an integrity/authenticity problem.
5. Evidence
Screenshots should show only the authorized test environment.
6. Status
Pending controlled lab verification.
