# Employee Email Security Awareness Package

## Audience and cadence
- New hires: 45-minute onboarding
- All staff: 30-minute quarterly refresher
- Administrators: 60-minute semiannual technical session
- Safe phishing simulation: quarterly with management and privacy approval

## 45-minute onboarding agenda
| Minutes | Topic |
|---|---|
| 0-10 | Phishing, impersonation and suspicious links |
| 10-20 | MFA, passkeys and account recovery |
| 20-30 | Handling sensitive data, DLP and encryption |
| 30-40 | Reporting suspicious messages and incidents |
| 40-45 | Knowledge check |

## Key lessons
- Verify unusual payment or credential requests using an independent channel.
- Inspect sender addresses and destination URLs; sender display names are not proof.
- Never share one-time codes or private encryption keys.
- Check recipient lists and classification before sending.
- Report suspicious mail using the approved channel rather than forwarding sensitive contents widely.

## Five-question quiz
1. Is a familiar display name sufficient to trust a message? **No.**
2. Should an MFA code be given to an IT caller? **No.**
3. Does TLS guarantee end-to-end encryption? **No.**
4. What should you do after sending confidential mail to the wrong recipient? **Report promptly via incident process.**
5. Can SPF alone verify a human sender's identity? **No.**

## Success measures
Track training completion, reporting rates, time-to-report and repeated confusion areas. Use aggregated measures and respect employee privacy.
